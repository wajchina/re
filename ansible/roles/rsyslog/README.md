# rsyslog role
## Summary
Build proxy server by squid
## Variables
* rsyslog_receiver  
  configure a server to receive logs, set rsyslog_receiver to yes.
* rsyslog_rsyslog_d_files  
  configure additional config files in /etc/rsyslog.d
