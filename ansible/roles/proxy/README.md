# proxy role
## Summary
Build proxy server by squid
## Variables
* squid_cache_dir  
  The directory where (and how) to cache
* squid_access_log  
  Location of squid's log file
* squid_image  
  squid docker image
* squid_version  
  squid docker image version
* squid_container  
  squid docker container name
* squid_port  
  squid docker expose port
